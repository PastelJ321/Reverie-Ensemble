# Open-library decisions — 0.5

Only source editions with actual files, rights and render evidence are advertised as installed/playable. Factory selection uses complete maps/dependencies and measured audio compatibility/size/breadth; perceptual tuning/noise/RAM certification remains separate.

| Source | Evidence / decision |
|---|---|
| [Meta Open Sound](https://github.com/facebookincubator/Meta-open-sound) | Instrument-folder CC0 licenses, original Git blobs/SHA-256, full Piano/Nylon/Steel acquisition and actual sfizz output. Piano is Opus-in-Ogg; libsndfile is enabled. Guitar default-channel derivatives avoid ignored lochan/hichan layering. Other Meta SFX licenses are not inherited. |
| [VCSL Keys](https://versilian-studios.com/vcsl-keys/) | Officially a lossless FLAC repack of overlapping VCSL keyboards, 3 grands/2 uprights/5 harpsichords. Existing selected/full VCSL coverage is not counted again under another pack name. |
| [Salamander](https://sfzinstruments.github.io/pianos/salamander/) | CC BY 3.0, 16 layers, releases/resonance and ARIA mapping variants. Not newly installed/certified here; attribution and full pedal/resonance comparison remain required. |
| [Karoryfer](https://shop.karoryfer.com/pages/free-samples) | Existing individually verified bass/guitar CC0 content is retained. Additional collections need individual rights and mapping checks; Marie Ork is not blanket-labeled CC0. |
| [SFZ drums](https://sfzinstruments.github.io/drums/) | SM Drums public-domain claim, Muldjord CC BY 4.0 and Big Rusty CC0 are distinct licenses/editions. No new complete kit integration is claimed merely from a catalog page; mic/hat/choke/RR/mixing and attribution need independent QA. |
| [FreePats](https://freepats.zenvoid.org/) | SoundFont/sample licensing is collection-specific. No new GM bank is bundled just because FluidSynth can load it. |

Factory PCM/Ogg sample bytes remain original. No per-note normalization, velocity thinning, cropped decays or repeated waveforms disguised as different instruments are used. Large redundant Kawai grand coverage remains optional; full Meta Piano provides the default all-key/four-layer piano within the factory budget. New sampled wind/string/organ content balances the retained compact sounds and percussion. Some source entries are physical variants; raw catalog entry totals are not a claim of that many unrelated instrument families.
