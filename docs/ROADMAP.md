# After 0.5.1: priorities for 0.6

1. Native CLAP editors, factory preset navigation and live parameter routing without rebuilding held-note/effect state.
2. Plugin delay compensation, latency/tail diagnostics and runtime crash bridge research; complete AU, then VST3 workflows with the same recording/state/export checks.
3. Physical MIDI keyboard/pedal/hotplug sessions, measured round-trip latency, callback profiling, streaming under disk pressure and long sessions with musicians.
4. Musician-led factory tuning/noise/release/drum review. Fill documented upright/felt, solo string and bass gaps; add high-quality licensed optional libraries only after full mapping/render audits.
5. Clean-machine signed/notarized distribution with replaceable LGPL dependencies, exact sources and Intel testing.
6. Buses/sends/automation, richer controller editing and loop takes/comping. Preserve old project sound and the independent Reverie core.
