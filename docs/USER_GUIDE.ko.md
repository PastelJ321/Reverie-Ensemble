# Reverie Ensemble 0.5 사용자 가이드

Reverie Ensemble은 샘플 악기, 내장 신시사이저, CLAP 플러그인, 비파괴 WAV 오디오 편집을 지원하는 macOS용 오프라인 디지털 오디오 워크스테이션입니다.

---

## 빠른 시작

Reverie Ensemble을 실행하면 네 개의 기본 트랙(**Piano**, **Strings**, **Bass**, **Percussion**)과 4마디 편곡이 포함된 시작 프로젝트가 열립니다.

- **Space** 키를 누르거나 상단 트랜스포트 바에서 **재생**을 클릭하면 시작 프로젝트를 바로 들어볼 수 있습니다.
- **편곡** 영역에서 트랙 헤더를 클릭해 연주하거나 편집할 트랙을 선택합니다.
- **Cmd+K**를 눌러 **가상 건반**을 열고 **키보드 연주**를 켜면 컴퓨터 키보드로 선택한 트랙의 악기를 연주할 수 있습니다.
- 편곡 영역의 MIDI 클립을 더블 클릭하면 하단 **피아노 롤**에서 노트를 수정할 수 있습니다.

---

## 1. 첫 프로젝트 만들기

1. **파일 → 새 프로젝트**(`Cmd+N`)를 선택해 새 시작 프로젝트를 열거나, **파일 → 프로젝트 이름 변경…**에서 현재 프로젝트의 이름을 바꿉니다.
2. 상단 트랜스포트 바에서 템포(**BPM**, `20–300`), 박자표(`4/4`, `3/4`, `6/8`, `7/8`), **반복 구간(박)**을 설정합니다.
3. **트랙** 메뉴 또는 편곡 영역 빈 공간의 우클릭 메뉴에서 트랙을 추가합니다.
   - **트랙 → MIDI 트랙 추가**(`Cmd+Shift+N`): 샘플 악기, 내장 신시사이저, CLAP 악기 플러그인을 연주하는 트랙을 추가합니다.
   - **트랙 → 오디오 트랙 추가**: WAV 파일을 가져오거나 마이크로 녹음하는 오디오 트랙을 추가합니다.
4. MIDI 트랙의 빈 레인을 더블 클릭하면 4박 길이의 빈 MIDI 클립이 생성됩니다.

---

## 2. 악기 선택하기

왼쪽 **사운드 라이브러리** 패널에는 설치된 모든 악기와 패치가 표시됩니다.

1. 편곡 영역에서 악기를 지정할 MIDI 트랙을 선택합니다.
2. 카테고리(**피아노 및 건반**, **현악기**, **목관악기**, **금관악기**, **기타 및 베이스**, **드럼 및 타악기**, **신시사이저**, **세계 민속악기**, **오케스트라**)를 선택하거나 **악기 또는 태그 검색** 입력란에 검색어를 입력합니다.
3. 악기를 클릭하면 하단 **패치** 목록에 사용 가능한 주법이나 음색 설정이 표시됩니다.
4. **미리 듣기**를 눌러 짧은 연주 구절을 들어보거나, **적용**(또는 악기 항목 더블 클릭)을 눌러 선택한 트랙에 악기를 지정합니다.
5. **새 악기 트랙**(확장 보기) 또는 우클릭 메뉴의 **새 트랙 만들기**를 선택하면 해당 악기가 불러와진 새 트랙이 바로 만들어집니다.
6. **확장 ↔**(`Cmd+Shift+B` 또는 **보기 → 악기 브라우저 확장**)을 누르면 카테고리, 악기 목록, 아트워크 및 패치 상세 정보를 3단 열로 넓게 볼 수 있습니다.

---

## 3. 사운드 라이브러리 설치 및 외부 악기 가져오기

Reverie Ensemble에는 오프라인에서 바로 사용할 수 있는 **Factory Library**와 **Community Essentials**(`CC0-1.0`)가 기본 포함되어 있습니다. 추가 사운드 팩은 사용자의 명시적인 요청이 있을 때만 다운로드합니다.

### 추가 사운드 팩 다운로드 및 로컬 설치

1. 사운드 라이브러리 하단의 **사운드 라이브러리 관리…**(또는 **⋯** 도구 메뉴 → **사운드 라이브러리 관리자…**)를 클릭합니다.
2. **사용 가능한 팩** 목록에서 원하는 항목을 선택해 용량, 패치 수, 필요한 엔진(`sfizz`), 라이선스 조건을 확인합니다.
3. **다운로드 / 업데이트**를 누르고 라이선스 안내를 확인하면 파일별 `SHA-256` 해시 검증을 거쳐 안전하게 설치됩니다.
4. 오프라인 환경에서는 **로컬 폴더 설치…**를 눌러 `pack.json`이 포함된 사운드 팩 폴더를 직접 선택해 설치할 수 있습니다.
5. 설치된 추가 팩을 삭제하려면 **설치된 팩** 목록에서 항목을 선택하고 **추가 팩 제거…**를 클릭합니다. 기본 제공 라이브러리는 삭제되지 않도록 보호됩니다.

### SFZ 및 SoundFont 파일 가져오기

1. 사운드 라이브러리 상단의 **⋯** 버튼을 누르고 **SFZ / SoundFont 가져오기…**를 선택합니다.
2. 디스크에서 `.sfz`, `.sf2`, `.sf3` 파일을 선택합니다.
3. 여러 프리셋이 담긴 SoundFont 파일은 **뱅크 : 프로그램** 선택 창에서 원하는 악기를 고를 수 있습니다. 가져온 악기는 **사용자 악기** 카테고리에 등록됩니다.

## 4. 컴퓨터 키보드로 연주

외부 CoreMIDI 건반이 없어도 Mac 키보드나 마우스로 모든 MIDI 트랙을 연주하고 녹음할 수 있습니다.

1. 편곡 영역에서 연주할 MIDI 트랙을 선택합니다.
2. **보기 → 가상 건반 / 컴퓨터 키보드 연주**(`Cmd+K`)를 선택하거나 트랜스포트 바의 **건반** 버튼을 클릭합니다.
3. 하단 가상 건반 우측 상단에서 **키보드 연주** 체크박스를 켭니다.
   - **흰건반**: `A` `S` `D` `F` `G` `H` `J` `K` (도–도)
   - **검은건반**: `W` `E` `T` `Y` `U` (도♯, 레♯, 파♯, 솔♯, 라♯)
   - **옥타브 내리기 / 올리기**: `Z` / `X`
   - **벨로시티 낮추기 / 높이기**: `C` / `V`
   - **서스테인 페달**: `Tab` 키 누르고 있기
4. 화면의 피아노 건반(`MIDI 21–108`)을 마우스로 클릭하거나 드래그하여 직접 연주할 수도 있습니다.

---

## 5. MIDI 녹음

1. 녹음할 MIDI 트랙을 선택합니다.
2. 우측 인스펙터의 **트랙 / 악기** 탭에서 **녹음 준비**를 켜거나, **트랜스포트 → 선택한 트랙 녹음 준비**(또는 트랙 우클릭 메뉴의 **녹음 준비**)를 실행합니다. 녹음 준비는 한 번에 하나의 트랙에서만 켤 수 있습니다.
3. 트랜스포트 바에서 **녹음 전 카운트: 없음**, **녹음 전 카운트: 1마디**, **녹음 전 카운트: 2마디** 중 하나를 선택하고, 필요하면 **메트로놈**을 켭니다.
4. 트랜스포트 바의 **녹음**(`R`) 버튼을 누릅니다.
5. 카운트가 끝나면 MIDI 건반이나 컴퓨터 키보드로 연주합니다.
6. **정지**(또는 **MIDI 녹음 완료**)를 누르면 녹음이 종료됩니다. 정지 시점까지 눌려 있던 노트는 자동으로 닫히며, 트랙에 편집 가능한 MIDI 클립이 생성됩니다.

---

## 6. 피아노 롤 편집

편곡 영역에서 MIDI 클립을 더블 클릭하거나 상단 트랜스포트 바의 **피아노 롤** 버튼을 누르면 노트 편집기가 열립니다.

- **노트 입력**: 빈 그리드 칸을 클릭합니다.
- **음높이 미리 듣기**: 왼쪽의 세로 피아노 건반을 클릭합니다.
- **노트 이동**: 노트를 좌우(박자 위치) 또는 상하(음높이)로 드래그합니다.
- **노트 길이 조절**: 노트의 오른쪽 끝을 드래그합니다.
- **복수 선택**: `Shift` 키를 누른 채 마우스를 드래그해 여러 노트를 선택합니다.
- **노트 삭제**: 노트를 선택하고 `Delete` 또는 `Backspace` 키를 누릅니다.
- **퀀타이즈**: 노트를 선택한 뒤(선택하지 않으면 클립 내 전체 노트 대상) 피아노 롤 상단 툴바에서 **퀀타이즈**(`Cmd+U`)를 누르면 현재 **스냅** 간격(`1/4`, `1/8`, `1/16`, `1/32`)에 맞춰 시작 위치가 정렬됩니다.
- **우클릭 메뉴**: 노트를 우클릭하면 **삭제**, **복제**, **퀀타이즈**, **벨로시티 설정…**(`1–127`), **길이 설정…**, **조옮김…**(`−48`~`+48`반음), **노트 속성…**을 실행할 수 있습니다.

---

## 7. 오디오 녹음 및 WAV 클립 편집

### 마이크 및 오디오 인터페이스 녹음

1. **트랙 → 오디오 트랙 추가**로 오디오 트랙을 만들고 선택합니다.
2. 해당 오디오 트랙을 **녹음 준비** 상태로 설정합니다.
3. **녹음**(`R`)을 누릅니다. macOS에서 마이크 권한을 요청하면 **시스템 설정 → 개인정보 보호 및 보안 → 마이크**에서 **Reverie Ensemble**을 허용하세요.
4. 녹음이 끝나면 **정지**(또는 **테이크 완료**)를 누릅니다. 녹음된 WAV 파일은 프로젝트 미디어 폴더에 기록되며 오디오 트랙에 클립으로 배치됩니다.

> **참고:** 녹음은 한 번에 하나의 녹음 준비된 트랙에서만 진행됩니다. 실시간 오디오 입력 모니터링과 하드웨어 지연 시간 보정은 0.5 버전에서 지원하지 않습니다.

### WAV 파일 가져오기 및 비파괴 트리밍

1. **파일 → WAV 가져오기…**(또는 오디오 트랙 우클릭 메뉴의 **오디오 가져오기…**)를 선택해 리프(RIFF) WAV 파일을 불러옵니다.
2. 클립을 좌우로 드래그해 시작 위치를 옮깁니다.
3. 클립의 오른쪽 끝을 드래그하면 원본 파일을 훼손하지 않고 재생 길이를 조절할 수 있습니다.

## 8. 믹서 및 채널 프로세싱 사용

상단 트랜스포트 바에서 **믹서**(`Cmd+M`)를 클릭하면 중앙 화면이 채널 스트립 믹서로 전환됩니다.

- **채널 스트립**: 각 트랙의 볼륨 페이더(**dB**), **팬**(`L`/`R`), **음소거**(`M`), **솔로**(`S`), **저역**/**고역** 셸프 EQ, 딜레이/리버브 센드 양을 조절할 수 있습니다.
- **채널 프로세싱**: 트랙 또는 **마스터** 스트립에서 **프로세싱…** 버튼을 누르면 트랙별 DSP 체인 설정 창이 열립니다.
  - **입력 게인 (dB)** 및 **출력 게인 (dB)**
  - **파라메트릭 EQ**: 사용 여부, **주파수 (Hz)**, **게인 (dB)**, **Q**
  - **컴프레서**: 사용 여부, **스레숄드 (dB)**, **비율**, **어택 (ms)**, **릴리스 (ms)**, **메이크업 게인 (dB)**
  - **피크 리미터**: 사용 여부, **스레숄드 (dB)**, **릴리스 (ms)**
- **악기 세부 조절**: 샘플 악기 트랙에서는 **톤 / 로우패스**, **릴리스**, **룸 / 리버브**, **활 어택**(찰현악기)을 조절할 수 있습니다. 내장 신시사이저 트랙에서는 우측 인스펙터의 **신스 컨트롤…**을 눌러 오실레이터 블렌드, 필터 엔벨로프, FM 인덱스, LFO, 비브라토, 디튠, 포르타멘토, 모노포닉/레가토 모드를 설정할 수 있습니다.

---

## 9. CLAP 플러그인 추가

Reverie Ensemble은 스테레오 **CLAP**(`1.x`) 악기 및 이펙트 플러그인을 지원합니다. 이 빌드에서는 Audio Units(AU) 및 VST3 호스팅을 지원하지 않습니다.

### 플러그인 검색 및 불러오기

1. **파일 → 오디오 플러그인…**(또는 확장 악기 브라우저 하단의 **오디오 플러그인…**)을 선택합니다.
2. 기본 CLAP 폴더(`/Library/Audio/Plug-Ins/CLAP`, `~/Library/Audio/Plug-Ins/CLAP`)가 자동으로 검색됩니다. 사용자 폴더를 추가하려면 **검색 폴더 추가…**를 누르고, 목록을 갱신하려면 **다시 검색**을 클릭합니다.
3. **악기 플러그인**을 사용하려면 목록에서 플러그인을 선택한 뒤 **트랙 만들기**를 눌러 새 트랙을 생성하거나, 기존 MIDI 트랙을 선택한 상태에서 불러옵니다.
4. **이펙트 플러그인**을 사용하려면 대상 트랙을 선택하거나 믹서의 **인서트…** 창에서 추가합니다.

### 트랙 인서트 및 파라미터 편집

1. 믹서 채널 스트립에서 **인서트…**를 클릭합니다(또는 **파일 → 플러그인 파라미터…** 선택).
2. **트랙 인서트** 창에서 이펙트 플러그인 **추가…**, **파라미터…** 편집기 열기, **바이패스** 전환, **믹스**(`0–100%`) 비율 조절, **위로 이동**, **제거**를 수행할 수 있습니다.

## 10. 프로젝트 저장 및 미디어 폴더 관리

1. **파일 → 저장**(`Cmd+S`) 또는 **파일 → 다른 이름으로 저장…**(`Cmd+Shift+S`)을 선택합니다.
2. 프로젝트 파일(`.reverie`)과 같은 위치에 `<프로젝트이름>.media/` 폴더가 생성되며, 가져온 WAV 파일과 녹음된 오디오 테이크, 사용자 샘플이 함께 보관됩니다.
3. 외부 대용량 SFZ 라이브러리를 참조하는 트랙은 원본 라이브러리 경로를 유지하므로, 프로젝트를 다른 위치로 옮길 때 해당 라이브러리가 설치되어 있어야 합니다.
4. Reverie Ensemble은 사용자가 직접 저장 명령을 실행할 때만 저장하며, 저장하지 않은 변경 사항이 있으면 종료하기 전에 저장 여부를 묻습니다.

---

## 11. WAV 내보내기

1. **파일 → 오디오 내보내기…**(`Cmd+E`)를 선택합니다.
2. **선택…** 버튼을 눌러 저장할 `.wav` 파일 경로를 지정합니다.
3. 내보내기 옵션을 설정합니다.
   - **샘플레이트**: `44100 Hz`, `48000 Hz`, `96000 Hz`
   - **비트 깊이**: `16-bit PCM`, `24-bit PCM`, `32-bit float`
   - **채널**: **스테레오** 또는 **모노 (L+R / 2)**
   - **출력 구간**: **프로젝트 전체**, **반복 구간**, **선택한 클립 구간**
   - **악기 릴리스 및 이펙트 잔향 포함**: 구간 끝 이후에 남는 악기 여운과 리버브/딜레이 잔향을 잘리지 않게 포함합니다.
   - **피크를 −1 dBFS로 노멀라이즈**: 다이내믹 컴프레션 없이 전체 레벨에 동일한 게인을 적용해 최대 피크를 `−1.0 dBFS`에 맞춥니다.
   - **정수형 PCM에 TPDF 디더 적용**: `16-bit` 또는 `24-bit` 정수형 PCM으로 내보낼 때 양자화 노이즈를 줄이기 위해 TPDF 디더를 적용합니다.
4. **내보내기**를 클릭합니다. 렌더링은 임시 파일에 먼저 기록되므로 중간에 **취소**해도 기존 파일은 손상되지 않습니다.

## 12. 자주 발생하는 오류 및 해결 방법

| 메시지 / 증상 | 원인 | 해결 방법 |
|---|---|---|
| **출력 장치가 연결되지 않았습니다. 오디오 재연결을 실행하세요.** | 사용 가능한 CoreAudio 출력 장치가 없거나 연결이 끊어졌습니다. | 오디오 인터페이스나 헤드폰 연결을 확인한 뒤 트랜스포트 바 우측의 오디오 상태 버튼을 누르거나, **파일 → 환경설정… → 오디오**에서 **장치 목록 새로고침** 후 **오디오 설정 적용**을 클릭하세요. 오프라인 WAV 내보내기는 출력 장치 없이도 작동합니다. |
| **마이크 접근 권한 거부됨** | macOS 개인정보 보호 설정에서 마이크 접근이 차단되었습니다. | **시스템 설정 → 개인정보 보호 및 보안 → 마이크**에서 **Reverie Ensemble**을 허용한 뒤 다시 녹음하세요. |
| **녹음 준비는 한 번에 하나의 트랙만 켜세요.** | 두 개 이상의 트랙이 동시에 녹음 준비 상태입니다. | 녹음할 트랙 하나만 남기고 다른 트랙의 **녹음 준비**를 해제하세요. |
| **WAV 파일 누락 — 원본 파일을 다시 가져와 연결하세요** | 오디오 클립이 참조하는 WAV 파일이 이동되었거나 삭제되었습니다. | 원본 WAV 파일을 프로젝트의 `.media/` 폴더에 복원하거나 다시 가져오세요. 파일이 없어도 기존 클립 배치와 길이는 그대로 보존됩니다. |
| **CLAP 플러그인을 초기화할 수 없습니다 / 플러그인을 검색할 수 없음** | 플러그인 번들이 손상되었거나 스테레오 입출력을 지원하지 않습니다. | `.clap` 번들이 검색 폴더에 정상 설치되어 있는지 확인하고 **오디오 플러그인…** 창에서 **다시 검색**을 누르세요. |
| **사용 중인 사운드 팩** | 현재 열린 프로젝트에서 사용 중인 사운드 팩을 삭제하려고 했습니다. | 해당 팩의 악기를 사용하는 트랙을 다른 악기로 바꾸거나 트랙을 삭제한 뒤 **사운드 라이브러리 관리자**에서 제거하세요. |
| **클리핑 발생 — 트랙 또는 마스터 볼륨을 낮추세요** | 마스터 출력 레벨이 `0 dBFS`를 초과했습니다. | 개별 트랙이나 **마스터** 볼륨을 낮추거나 **채널 프로세싱**에서 **피크 리미터**를 켜고, 상단 오디오 상태 버튼을 클릭해 클리핑 표시를 초기화하세요. |

## 13. 기본 사운드 라이브러리 악기 안내

기본 제공되는 **Ensemble 0.5 Factory Library**(`assets/sounds/factory05`)와 **Community Essentials**(`assets/sounds/essentials03`)는 **Versilian Community Sample Library(VCSL)**, **VSCO 2 Community Edition**, **Splendid Grand**, **Salamander Drumkit**, **Karoryfer Samples**의 퍼블릭 도메인(`CC0-1.0`) 녹음 샘플과 보정된 내장 신시사이저 패치로 구성되어 있습니다.

### 피아노 및 건반
- **콘서트 그랜드 피아노 (Concert Grand Piano)**: Akai Steinway III 멀티샘플(`VCSL / Splendid Grand`, `CC0-1.0`)을 기반으로 한 그랜드 피아노입니다. 넓은 다이내믹 범위와 선명한 어택을 갖추고 있으며 *Concert Sustain*, *Intimate Felt*, *Bright Studio* 패치를 지원해 독주와 반주 모두에 적합합니다.
- **업라이트 피아노 (Upright Piano)**: Knight K10 업라이트 피아노(`VCSL`, `CC0-1.0`)를 녹음한 악기로, 밀도 있는 중음역과 나무 공명이 특징입니다. *Room Upright*, *Soft Practice*, *Tack Piano* 패치를 제공하며 소편성 곡이나 차분한 반주에 어울립니다.
- **일렉트릭 피아노 (Electric Piano)**: 벨로시티 레이어가 적용된 일렉트릭 피아노(`VCSL`, `CC0-1.0`)로 *Stage Mark*, *Warm Lounge*, *Bell Tines* 패치를 제공합니다.
- **오르간 (Pipe / Reed Organ)**: `8'` 및 `4'` 스톱 구성의 오르간(`VCSL`, `CC0-1.0`)으로 일정한 서스테인과 차분한 화성 배경을 만듭니다.

### 현악기 및 하프
- **바이올린 (Solo Violin)** / **비올라 (Solo Viola)**: 독주 찰현악기(`VCSL`, `CC0-1.0`)로 지속음(*Arco Vibrato* / *Lyric Sustain*), 부드러운 실내악 톤(*Warm Chamber*), 피치카토(*Pizzicato*) 패치를 지원합니다. 트랙 인스펙터에서 **활 어택**, **릴리스**, **룸 / 리버브**를 조절할 수 있습니다.
- **첼로 (Solo Cello)**: 중저음역 선율과 베이스 라인을 모두 소화하는 독주 첼로(`VCSL`, `CC0-1.0`)로 *Lyric Sustain*, *Warm Legato*, *Pizzicato* 패치를 포함합니다.
- **콘트라베이스 (Upright Bass)**: 오케스트라 저음과 재즈 리듬 섹션에 쓰이는 어쿠스틱 베이스(`VCSL`, `CC0-1.0`)로 활주법(*Orchestral Arco*)과 피치카토(*Jazz Pizzicato*)를 지원합니다.
- **현악 앙상블 (String Section)**: 전 음역에 걸쳐 매핑된 스트링 섹션(`VCSL`, `CC0-1.0`)으로 *Ensemble Sustain*, *Soft Chamber*, *Marcato Bow* 패치를 제공합니다.
- **콘서트 하프 (Concert Harp)**: 맑은 어택과 긴 공명을 지닌 콘서트 하프(`VCSL`, `CC0-1.0`)입니다.

### 목관악기 및 금관악기
- **플루트 (Concert Flute)**, **오보에 (Oboe)**, **클라리넷 (Clarinet)**, **바순 (Bassoon)**: 오케스트라 목관악기군(`VCSL`, `CC0-1.0`)으로 기본 서스테인 패치와 짧은 호흡·스타카토 변형 패치를 제공합니다.
- **호른 (French Horn)**, **트럼펫 (Trumpet)**, **트롬본 (Trombone)**, **튜바 (Tuba)**: 오케스트라 금관악기군(`VCSL`, `CC0-1.0`)으로 선명한 브라스 어택부터 부드러운 코랄 톤까지 표현할 수 있습니다.

### 기타 및 베이스
- **어쿠스틱 기타 (Acoustic Guitar)**: 어쿠스틱 기타(`VCSL`, `CC0-1.0`) 샘플로 *Natural Picked*, *Warm Fingered*, *Muted Pluck* 패치를 지원합니다.
- **일렉트릭 기타 (Electric Guitar)**: 클린 톤으로 녹음된 싱글코일 일렉트릭 기타(`VCSL`, `CC0-1.0`)로 앰프 시뮬레이터나 이펙트 체인과 조합하기 좋습니다.
- **일렉트릭 베이스 (Electric Bass)**: 2단 벨로시티 레이어와 라운드로빈 샘플이 적용된 핑거 일렉트릭 베이스(`Karoryfer / Fashionbass`, `CC0-1.0`)입니다. *Fingered Studio*, *Deep Sub*, *Pick Attack* 패치로 선명한 어택이나 둥근 저음을 표현합니다.

### 타악기 및 세계 민속악기
- **마림바 (Marimba)**, **실로폰 (Xylophone)**, **비브라폰 (Vibraphone)**, **글로켄슈필 (Glockenspiel)**, **튜뷸러 벨 (Tubular Bells)**: 오케스트라 선율 타악기(`VCSL`, `CC0-1.0`)입니다.
- **칼림바 (Kalimba)** / **발라폰 (Balafon)**: 짧은 여운과 민속적인 타건감을 지닌 칼림바와 발라폰(`VCSL`, `CC0-1.0`)입니다.
- **스튜디오 드럼 키트 (Studio Drum Kit)**: General MIDI 드럼 음역(`MIDI 35–59`: 킥, 스네어, 림샷, 하이햇, 탐, 크래시, 라이드)에 매핑된 어쿠스틱 드럼 키트(`VCSL / Salamander Drumkit`, `CC0-1.0`)입니다. *Studio Kit*, *Tight Dry Kit*, *Room Kit* 패치를 지원합니다.
- **오케스트라 타악기 (Orchestral Percussion)**: 팀파니, 그란 카사(베이스 드럼), 심벌 스웰이 포함된 콘서트 타악기 키트(`VCSL`, `CC0-1.0`)입니다.

### 내장 신시사이저
- **Warm Analog Pad** / **Glass Choir Pad**: 풍부한 스테레오 공간감을 제공하는 폴리포닉 패드 신시사이저입니다.
- **Analog Bass Synth** / **Mono Synth Lead**: 모노포닉 레가토와 포르타멘토 슬라이드를 지원하는 베이스 및 리드 신시사이저입니다.
- **FM Electric Keys** / **Plucked Synth Harp**: 벨 음색의 FM 건반과 짧은 디케이의 아르페지오 플럭 신시사이저입니다.
